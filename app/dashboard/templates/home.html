The monitor groups captured packets into flows, checks rules and machine-learning outliers, and stores the results for review. The accompanying CN tools connect those observations to the concepts we study.

05 / BEFORE YOU START

A few useful
details.

Is the dashboard showing live traffic?

It shows saved records until you start capture. Open the monitor, choose Capture controls, select your adapter, and start capture. The status label distinguishes live capture from saved data.

What is needed for capture on Windows?

Install the Python requirements and Npcap. If your Npcap installation restricts access, run the dashboard terminal as Administrator. The included saved records and CN tools work without starting capture.

Does an alert mean an attack happened?

No. A rule match or ML anomaly identifies a pattern that needs review. Inspect the flow fields and context. The included ML dataset is a small academic baseline, and this project does not automatically block traffic.

Which networking concepts can we demonstrate?

Packet protocols, IP addresses, ports, directional flows, TCP flags, and captured traffic rates. CN tools also includes IPv4 subnetting, CRC, Internet checksum, Hamming code, and an OSI layer explorer.
